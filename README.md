# Ganesh Suthar — Portfolio

Ops-console themed portfolio. React + Vite, single-component architecture, live GitHub telemetry.

## Run locally
```bash
npm install
npm run dev
```

## Deploy to Vercel
1. Push this folder to a GitHub repo
2. vercel.com → Add New Project → import the repo
3. Vercel auto-detects Vite — just click Deploy

## Before going live
- Replace `https://ganeshsuthar.dev/` with your real domain in:
  - `index.html` (canonical, og:url, og:image, JSON-LD)
  - `src/Portfolio.jsx` (SEO config at the top)
  - `public/robots.txt` and `public/sitemap.xml`
- Google Doc resume: Share → "Anyone with the link — Viewer"
